# Stage 1: Project MVP

1. When a user opens this app the first thing the see is a difficulty selector (Initially a login/sign up page but that can be implemented later)

2. There are 3 difficulty easy midium and hard, each with a small list of images (but initially one each)

3. Difficulty is based on how crowded the image is and the amount of characters to find.

4. When a user selects an image and clicks start, the game begins.

5. There is a timer that times how long it took for the user to complete searching the image, found at the top of the page.

6. Time is recorded and stored in highscore, Highscore is tracked for easy, midium and hard game modes

7. The users top 3 time is recorded.

8. The game displays a large, screen wide searchable image

9. Users are able to click on the image, this shows a pop up of target characters.

10. Users are able to select any target character if they believe the coordinate of the screen selected has that character

11. The selected coordinate is checked along saved coordinate, If it matches that character is greyed out and pop up turns green, and marked as found

12. Else make the pop up red to indicate incorrect selection (any other feature can be used here, dont yet have the best one yet)

13. Users can right click to remove pop up if misclicked.

14. If all target character is found, timer is stopped and saved, user can no longer interact with image and game won is displayed.

15. Time it took to find all target is displayed and highscores too.

16. A button for replay or exit(back to main menu) is displayed
